# Matheesha Wijesekara — Squash Portfolio

Modern, dark-themed sports portfolio built with Next.js App Router, Tailwind CSS, and Framer Motion.

## Highlights

- Animated hero, stats, podium, and media sections
- Dedicated pages for achievements, gallery, videos, media, and sponsors
- Lightbox gallery and YouTube embeds
- Fully responsive, sports-inspired UI

## Getting Started

Install dependencies and start the dev server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project Structure

- `app/` — App Router pages
- `components/` — Reusable UI components
- `lib/siteData.js` — Centralized content data

## Customize Content

Update stats, achievements, videos, and media entries in `lib/siteData.js`.
